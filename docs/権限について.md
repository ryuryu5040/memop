# 権限について

## マップの公開範囲

- **URL限定公開**（画面では「公開」）は、共有されたマップの URL からログインせずに開けます。共有フォルダの中にも表示されます。
- **非公開**は、作成者と管理者が開けます。他の人が URL を直接開くと「マップが見つかりません」と表示されます。

## ユーザーごとにできること

表の「自分のマップ」「自分のピン」は、それぞれ自分が作成したものを指します。

| 利用者 | URL限定公開マップ | 非公開マップ |
| --- | --- | --- |
| ログインしていない人 | マップとピンを閲覧できる。 | 閲覧できない。 |
| ログイン済みの一般ユーザー | マップとピンを閲覧できる。ピンを追加でき、自分のマップ・ピンは編集・削除できる。 | 自分のマップを閲覧・編集・削除できる。中のピンを閲覧でき、ピンの追加や自分のピンの編集・削除ができる。他のユーザーのマップとその中のピンは閲覧できない。 |
| 管理者 | 他のユーザーが作成したマップ・ピンも閲覧・編集・削除できる。ピンを追加できる。 | 他のユーザーが作成したマップ・ピンも閲覧・編集・削除できる。ピンを追加できる。 |

- マップの編集では、タイトル・説明・公開範囲を変更できます。管理者がマップやピンを編集しても、元の作成者は保持されます。
- ログイン済みのユーザーは、閲覧できるピンにコメントを投稿し、自分のコメントを削除できます。
- 管理者はヘッダーの「マップ管理」から両方の公開範囲のマップを開けます。マップは詳細画面のメニュー、ピンはピンを開いたパネルから編集・削除できます。
- めもっぷにアップロードしたマップ画像も、マップと同じ閲覧権限で表示されます。

## ユーザー管理

- 管理者はヘッダーの「ユーザー管理」から、登録ユーザーと現在の権限を確認し、管理者権限を付与・解除できます。最後の管理者の権限は解除できません。
- 一覧には Supabase Auth の GitHub 連携情報に保存されたユーザー名と、メールアドレス、ユーザー ID が表示されます。ログイン名の情報がない場合は「GitHub ユーザー名なし」と表示されます。
- 一覧の取得と権限の変更は、Supabase 側でも操作した人が管理者か確認します。変更されたユーザーの画面は、ページを再読み込みするか、別のタブから戻ると権限を確認し直します。
- この機能を有効にするには、既存の `is_map_admin()` がある Supabase プロジェクトの SQL Editor で、[ユーザー管理用の SQL](sql/issue-11-admin-users.sql)、[GitHub ユーザー名を追加する SQL](sql/issue-11-admin-github-usernames.sql) の順に、それぞれファイル全体を実行します。ユーザー管理用の SQL を適用済みの場合は、GitHub ユーザー名を追加する SQL を実行します。
